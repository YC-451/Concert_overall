# 时代峰峻商城 SKU 监控 —— 使用教程（Windows / Mac）

这个小程序定时查询商城商品各个款式的状态（有货/售罄、热度、库存），
把每次的结果和发生的变化都记在表格里，有重要变化时还可以推送到手机（Bark）。

- **不需要打开时代峰峻 App，也不需要手机模拟器**，程序直接向商城服务器查询。
- 目前**不需要 token**，`config.json` 里的 token 留空即可。
- Windows 和 Mac 都能用：先看自己系统对应的部分（**一** 或 **二**），再看 **三、通用说明**。

---

# 一、Windows 使用方法

## 第 1 步：安装 Python（只需一次）

1. 打开 <https://www.python.org/downloads/> ，点黄色的 **Download Python 3.x.x** 按钮下载。
2. 双击下载好的安装包。
3. **非常重要：在安装界面最下方，勾选 “Add Python to PATH”（或 “Add python.exe to PATH”）**，再点 **Install Now**。
4. 等它装完，点 Close。

## 第 2 步：安装 requests（只需一次）

1. 按键盘上的 **Win 键**，输入 `cmd`，回车，会打开一个黑色窗口（命令提示符）。
2. 在里面输入下面这行，然后回车：

   ```
   pip install requests
   ```

3. 看到 `Successfully installed ...` 或 `Requirement already satisfied` 就说明好了。

> 如果提示 “pip 不是内部或外部命令”，说明第 1 步没勾选 “Add Python to PATH”。重新运行安装包，选 Modify / 卸载后重装，并勾上那个选项。

## 第 3 步：准备配置文件（只需一次）

1. 把整个文件夹（里面有 `monitor.py`、`config.example.json` 等）放到一个好找的位置，比如桌面上的 `tf_monitor` 文件夹。
2. 在文件夹里把 `config.example.json` **复制一份**，把复制出来的文件**改名为 `config.json`**。
   - 如果看不到 `.json` 后缀：在文件夹窗口上方点 “查看” → 勾选 “文件扩展名”。
3. 右键 `config.json` → 打开方式 → **记事本**，按 [三-1 配置文件怎么填](#1-配置文件怎么填) 修改，保存（Ctrl + S）。

## 第 4 步：防止电脑睡眠（只需一次）

电脑睡着了程序就会暂停。

1. 开始菜单 → **设置** → **系统** → **电源和睡眠**（Win11 是 “电源” → “屏幕和睡眠”）。
2. 把 “**睡眠**” 下面的选项（接通电源时）都改成 “**从不**”。
   - “关闭屏幕” 可以不改，屏幕黑了不影响程序运行。
3. 如果是笔记本：请插着电源，并且**不要合上盖子**（或在 “控制面板 → 电源选项 → 选择关闭盖子的功能” 里改成 “不采取任何操作”）。

## 第 5 步：运行

1. 打开放程序的文件夹，在窗口上方的**地址栏**里点一下，输入 `cmd`，回车。
   这样会在这个文件夹里直接打开黑色窗口。
2. 输入下面这行，回车：

   ```
   python monitor.py
   ```

3. 看到类似下面的行就说明在正常运行（详见 [三-2](#2-运行时窗口里显示什么)）。

**请保持这个黑色窗口开着，不要关闭。** 可以最小化。

> ⚠️ **不要用鼠标在黑色窗口里点来点去！** Windows 的命令提示符在你点击/选中文字时会**暂停程序**（窗口标题会出现 “选择”）。如果不小心点了，按一下 **Esc** 或 **回车** 就会继续。

## 怎么停止

在黑色窗口里按 **Ctrl + C**。看到 “已停止监控” 就停了。

# 二、Mac 使用方法

## 第 1 步：安装 Python（只需一次）

1. 打开 <https://www.python.org/downloads/> ，点黄色的 **Download Python 3.x.x** 按钮，下载 macOS 安装包（`.pkg`）。
2. 双击安装包，一路点 “继续” → “同意” → “安装”，输入电脑开机密码，直到完成。

> 请用官网的安装包。如果你以前用 Homebrew 装过 Python，第 2 步可能会报 `externally-managed-environment` 错误，装一下官网版本就好。

## 第 2 步：安装 requests（只需一次）

1. 按 **Command + 空格**，输入 `终端`（或 `Terminal`），回车，会打开一个终端窗口。
2. 输入下面这行，回车：

   ```
   pip3 install requests
   ```

3. 看到 `Successfully installed ...` 或 `Requirement already satisfied` 就说明好了。

## 第 3 步：准备配置文件（只需一次）

1. 把整个文件夹放到一个好找的位置，比如 “桌面” 上的 `tf_monitor` 文件夹。
2. 在访达（Finder）里选中 `config.example.json`，按 **Command + C**、**Command + V** 复制一份，
   把复制出来的文件**改名为 `config.json`**（如果弹窗问是否更改扩展名，选 “使用 .json”）。
3. 右键 `config.json` → 打开方式 → **文本编辑**，按 [三-1 配置文件怎么填](#1-配置文件怎么填) 修改，保存（Command + S）。

> ⚠️ Mac 的 “文本编辑” 会把你**手打**的英文引号自动变成中文弯引号 `“ ”`，导致程序读不了。
> 建议只改数字、把 token 粘贴到已有的两个引号中间，不要自己打引号。
> 或者先关掉：文本编辑菜单栏 → **编辑** → **替换** → 取消勾选 **智能引号**。

## 第 4 步：运行（同时防止睡眠）

1. 打开 “终端”，输入 `cd`，**再打一个空格**，然后**把 `tf_monitor` 文件夹从访达拖进终端窗口**，按回车。
   （这一步是让终端 “进入” 这个文件夹。）
2. 输入下面这行，回车：

   ```
   caffeinate -i python3 monitor.py
   ```

   - 前面的 `caffeinate -i` 会让 Mac 在程序运行期间**不睡眠**，程序停止后自动恢复正常，不用改系统设置。
   - 屏幕可以变黑或锁屏，不影响运行。
3. 看到类似下面的行就说明在正常运行（详见 [三-2](#2-运行时窗口里显示什么)）。

**请保持终端窗口开着。** 可以最小化。

> 💡 如果是 MacBook：请**插着电源**，并且**不要合上盖子**（合盖后即使有 caffeinate 也可能睡眠）。

## 怎么停止

在终端窗口里按 **Control + C**（是 Control 键，不是 Command）。看到 “已停止监控” 就停了。

# 三、通用说明（Windows 和 Mac 一样）

## 1. 配置文件怎么填

`config.json` 的内容类似这样：

```json
{
  "token": "",
  "goods_ids": [1891],
  "interval_seconds": 60,
  "bark_key": ""
}
```

- `token`：登录凭证。**目前不需要，留空即可**（两个英文引号中间什么都不写）。
  如果以后程序提示 401/403，再把 token 粘贴在两个引号中间（不用带 `Bearer`）。
- `goods_ids`：要监控的商品编号，多个用英文逗号隔开，例如 `[1891, 1193]`。
- `interval_seconds`：多少秒查一次。平时 60 就够；**新品上架时建议改成 10**（最小只能填 10）。
- `bark_key`：iPhone 上 Bark App 里的 key（链接 `https://api.day.app/` 后面那一串）。不需要推送就留空。

> 所有符号都必须是**英文**的引号 `"` 和逗号 `,`。
> 改完 `config.json` 后，需要停止程序再重新运行才会生效。

## 2. 运行时窗口里显示什么

每查询一次多出一行，类似：

```
2026-11-02 12:25:28 [1891] 组合:售罄 | 马嘉祺:售罄 | 丁程鑫:有货 | 宋亚轩:有货热4 | ...
```

- 绿色 “有货”、红色 “售罄”，“热4” 表示热度等级是 4（没有 “热” 字就是 0）。
- 启动后的**第一次**查询只作为 “基准”，不会算作变化。
- 有变化时会出现一大块黄色的 `!!!!!!` 提示，写明是哪个款、什么变了、发生在哪两次查询之间。
- 红色的文字是错误提示（比如网络断了），程序会自己重试，不用管它。

## 3. 新品上架时怎么用（只看谁先热销）

如果只想知道新商品上架后哪个款先出现热度（hotSell）、什么时候出现，**不用连续跑好几天**：

1. **提前拿到新商品的 goodsId**，填进 `goods_ids`。
2. 把 `interval_seconds` 改成 `10`，这样能精确到 10 秒左右。
3. **在上架前 5 分钟左右启动**程序。
   - 如果商品还没上架、查不到，窗口会出现红色错误提示，这是正常的，程序会自己继续重试；上架后会自动开始记录。
4. 上架后看 `events.csv` 里 `hotSell` 那几行：哪个款、从几变成几、在哪两个时间之间变的。
5. 觉得够了（比如所有款都有热度了，或者过了你关心的时间段）就停止。

> 第一次建议多跑一会儿（比如上架后 1～2 小时），先摸清热度一般在上架后多久出现，以后再缩短运行时间。

## 4. 数据文件在哪里

都在程序文件夹里的 **`data`** 文件夹：

| 文件 | 内容 |
|---|---|
| `snapshots.csv` | 每次查询、每个款式一行的完整记录（文件会越来越大，正常） |
| `events.csv` | **只有发生变化时才记录**：哪个款、哪个字段、从什么变成什么、变化发生在哪两次查询之间 |
| `errors.log` | 所有错误（网络断、token 过期等），可以用记事本 / 文本编辑打开 |
| `raw` 文件夹 | 启动时和每次有变化时，服务器返回的完整原始数据 |

多次运行的数据会**接着往后写**，不会覆盖之前的记录。如果想重新开始，把 `data` 文件夹改个名字或挪走即可。

## 5. 怎么用 Excel 打开

直接双击 `events.csv` 或 `snapshots.csv` 就会用 Excel 打开（Mac 也可以用 Numbers），中文不会乱码。

> 💡 **Windows 用户：建议先把 csv 文件复制一份，再打开复制出来的那份。**
> Windows 上 Excel 打开文件时会把它 “锁住”，程序暂时写不进去。程序会先把数据存在内存里，
> 等你关掉 Excel 后自动补写，不会丢数据，但窗口里会出现红色提示。看完记得关掉 Excel。

## 6. 手机会收到哪些推送（填了 bark_key 才有）

- **库存出现 0 和 999 以外的数字**（最重要，会用 “时效性通知” 推送）
- 任何款式的 **售罄 / 回流**、**热度** 变化
- **token 失效**（接口返回 401/403）：之后每 10 分钟重试一次。请在 `config.json` 里填上新的 token，然后停止程序再重新运行。
- **连续 5 次请求失败**（比如网络断了）
- 出过问题后**恢复正常**时，也会推送一条 “监控已恢复”

## 7. 常见问题

- **提示 “找不到 config.json”**：文件名不对。确认是 `config.json`，而不是 `config.json.txt`（Windows 打开 “文件扩展名” 显示就能看出来；Mac 右键 → 显示简介 看 “名称与扩展名”）。
- **提示 “config.json 格式有误”**：多半是用了中文引号/逗号，或者少了逗号。对照上面的示例检查。
- **Mac 提示 `No such file or directory`**：第 4 步的 `cd` 没进入正确的文件夹，重新拖一次文件夹。
- **Mac 输入 `python3` 后弹窗要安装 “命令行开发者工具”**：说明第 1 步的 Python 没装好，重新安装官网的 `.pkg`。
- **一直显示 “网络错误”**：检查电脑能不能上网。网络恢复后程序会自动继续。
- **显示 “HTTP 429 被限流”**：程序会自动等 5 分钟再试，不用管。
