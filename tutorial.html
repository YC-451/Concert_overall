时代峰峻商城 · 款式状态监控

从零开始的使用教程

这个小程序会定时查一次商品每个款式的状态：有货还是售罄、热度几级、库存多少。结果自动记进表格，有变化时还能推送到手机。

不用打开 App 不用手机模拟器 目前不用 token Windows 和 Mac 都能用
第一部分

准备和运行

先选你的电脑系统，下面的步骤会跟着变。标着“一次”的步骤只需要做一次，以后每次只做最后的“运行”。

  1. 拿到程序文件一次

    • 如果别人直接发给你一个压缩包：解压到一个好找的位置，比如桌面上的 tf_monitor 文件夹。
    • 如果是从 GitHub 下载：打开项目页面，点绿色的 Code 按钮 → Download ZIP，下载后解压。

    文件夹里应该能看到 monitor.py、config.example.json、README.md 这几个文件。

  2. 安装 Python一次

    1. 打开 python.org/downloads，点黄色的 Download Python 3.x.x。
    2. 双击下载好的安装包。
    3. 双击下载好的 .pkg 安装包，一路点“继续”“同意”“安装”，输入开机密码。
    4. 在安装界面最下方勾选 Add Python to PATH，再点 Install Now。
    5. 等它装完，点关闭。
    最容易漏的一步一定要勾选 “Add Python to PATH”。漏了的话，后面会提示“不是内部或外部命令”。
    请用官网安装包以前用 Homebrew 装过 Python 也没关系，再装一个官网版本，后面最省事。

  3. 安装 requests 组件一次

    按键盘上的 Win 键，输入 cmd，回车，会打开一个黑色窗口。在里面粘贴下面这行，回车：

    按 ⌘ Command + 空格，输入“终端”，回车。在打开的窗口里粘贴下面这行，回车：

    pip install requests
    pip3 install requests

    看到 Successfully installed 或 Requirement already satisfied 就好了。

  4. 准备配置文件一次

    1. 在文件夹里把 config.example.json 复制一份，把复制出来的那份改名为 config.json。
    2. 看不到 .json 后缀的话：文件夹窗口上方点“查看” → 勾选“文件扩展名”。
    3. 如果弹窗问是否更改扩展名，选“使用 .json”。
    4. 右键 config.json → 打开方式 → 记事本。
    5. 右键 config.json → 打开方式 → 文本编辑。

    内容长这样，一般只需要改 goods_ids：

    {
  "token": "",
  "goods_ids": [1891],
  "interval_seconds": 60,
  "bark_key": ""
}
    项目怎么填
    token留空即可。以后程序提示 401/403 时，再把登录凭证粘贴到两个引号中间。
    goods_ids要看的商品编号，多个用英文逗号隔开，例如 [1891, 1193]。
    interval_seconds几秒查一次。平时填 60；新品上架前后填 1（一秒一次），看完改回 60。
    bark_key想收到手机推送就填 Bark App 里的 key，不需要就留空。
    引号和逗号必须是英文的 用记事本编辑一般不会出问题，保存用 Ctrl + S。 “文本编辑”会把手打的引号自动变成中文弯引号。只改数字、把内容粘贴到已有的引号中间就不会出错；或者在菜单栏 编辑 → 替换 里取消勾选“智能引号”。保存用 ⌘ + S。

  5. 关掉电脑睡眠一次

    1. 开始菜单 → 设置 → 系统 → 电源和睡眠（Win11 是“电源” → “屏幕和睡眠”）。
    2. 把“睡眠”改成“从不”。“关闭屏幕”不用改，屏幕黑了不影响。
    3. 笔记本请插着电源，不要合上盖子。

  6. 运行

    打开放程序的文件夹，在窗口上方的地址栏里点一下，输入 cmd，回车。会在这个文件夹里直接打开黑色窗口。然后粘贴这行，回车：

    打开“终端”，先输入 cd 和一个空格，然后把 tf_monitor 文件夹从访达拖进终端窗口，回车。然后粘贴这行，回车：

    python monitor.py
    caffeinate -i python3 monitor.py

    前面的 caffeinate -i 会让 Mac 在程序运行期间不睡眠，程序停了就自动恢复，不用改系统设置。MacBook 请插着电源，不要合盖。

    窗口要一直开着，可以最小化。想停下时按 CtrlControl + C（是 Control 键，不是 Command）。

    不要用鼠标点黑色窗口里面点一下或选中文字，程序就会暂停（窗口标题出现“选择”）。不小心点了，按 Esc 或回车就能继续。
第二部分

看懂窗口里的字

正常运行时，每查一次多出一行。下面是一个示例：

[1891] 启动后的第一次成功请求，作为基准，不算变化。 13:33:21 [1891] 组合:售罄 | 马嘉祺:售罄 | 丁程鑫:有货 | 张真源:有货 ... 13:34:21 [1891] 组合:售罄 | 马嘉祺:售罄 | 丁程鑫:有货热4 | ... !!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!! 发现变化！ 时代少年团特别纪念明信片（1891） 变化发生在 13:33:21 到 13:34:21 之间 ▶ 丁程鑫：热度 0 → 4 !!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!! [13:35:21] [1891] 请求失败（连续第 1 次）：网络错误
绿色 有货这个款现在能买。
红色 售罄这个款卖完了。
黄色 热4这个款的热度等级，没写就是 0。
黄色 !!!!有东西变了，写明是哪个款、变成什么、发生在哪两次查询之间。
红色 请求失败网络断了之类的问题。程序会自己重试，不会当成售罄，不用管它。

热度等级

0无
1小火苗
2中火
3大火
4“热”字章

目前看到的新商品，都是从 0 直接跳到 4。

第三部分

新品上架时怎么用

只想知道新商品哪个款先变热、什么时候变热的话，只需要在上架前后跑一段时间。

  1. 提前抓包拿到新商品的 goodsId：在 App 里点进商品页，在抓到的请求里找 getShelvesSku/数字，那串数字就是编号。填进 goods_ids，interval_seconds 改成 1（一秒查一次）。
  2. 上架前 5 分钟启动程序。还没上架、查不到时会显示红色错误，这是正常的，程序会一直重试，上架后自动开始记录。
  3. 上架后打开 data 文件夹里的 events.csv，找“字段”一栏是 hotSell 的行：哪个款、从几变成几、在哪两个时间之间变的。
  4. 看够了按 CtrlControl + C 停止。第一次建议多跑 1～2 小时，摸清热度一般多久出现。
第四部分

数据保存在哪里

都在程序文件夹里的 data 文件夹。多次运行会接着往后写，不会覆盖。想从头开始，把 data 文件夹改个名字就行。

文件里面是什么
events.csv最常看的。只记录变化：哪个款、哪个字段、从什么变成什么、发生在哪两次查询之间。
snapshots.csv每次查询、每个款一行的完整记录，会越来越大，正常。
errors.log所有错误，用记事本或文本编辑打开。
raw 文件夹启动时和每次变化时，服务器返回的完整原始数据。

双击 csv 文件就会用 Excel 打开（Mac 也可以用 Numbers），中文不会乱码。

Windows 小提示Excel 打开 csv 时会锁住文件，程序暂时写不进去，会先存在内存里，关掉 Excel 后自动补写，不会丢数据。更省心的做法是先复制一份，打开复制出来的那份。
第五部分

手机会收到哪些推送

填了 bark_key 才会推送。

  • 库存出现 0 和 999 以外的数字：最重要，用“时效性通知”推送，专注模式下也会弹出。
  • 任何款式售罄、回流，或者热度变了。
  • token 失效（401/403）：之后每 10 分钟重试一次。在 config.json 填上新 token，停止后重新运行。
  • 连续 5 次请求失败，比如网络断了。
  • 出过问题后恢复正常，也会推送一条。
第六部分

电脑睡着或重启了怎么办

先看窗口还在不在，分两种情况：

情况怎么做
窗口还在只是睡眠了。把电脑唤醒就行，什么都不用按。程序会自己继续，一般一分钟内就会出现新的一行。刚唤醒时网络还没连上，可能会出现几行红色的“网络错误”，是正常的。
窗口没了电脑重启过（比如系统自动更新）或者窗口被关掉了。重新做一遍“运行”那一步就行，之前的数据都还在，新数据会接着往后写。

怎么确认在正常运行？看窗口最后一行的时间，如果是刚刚的时间就没问题。

睡眠期间的数据会怎样电脑睡着时什么都记不到。如果这段时间里有变化，唤醒后的第一次查询仍然会记下来。只是 events.csv 里“上次成功时间”会是睡眠前的时间，也就是说只知道变化发生在这整段时间里的某个时刻。所以重要的时间段一定要防止睡眠。
Mac 合上盖子会睡眠caffeinate 只能防止“闲置自动睡眠”，合盖还是会睡。唤醒后程序会自己继续。
Windows 自动更新可能会重启电脑重要的日子前，可以在 设置 → Windows 更新 里点“暂停更新”。
第七部分

遇到问题

提示“找不到 config.json”
文件名不对。确认是 config.json，不是 config.json.txt。Windows 打开“文件扩展名”显示就能看出来；Mac 右键 → 显示简介，看“名称与扩展名”。
提示“config.json 格式有误”
多半是用了中文引号、中文逗号，或者少了逗号。对照上面的示例检查一遍。
提示“pip 不是内部或外部命令”
安装 Python 时没勾选 “Add Python to PATH”。重新运行安装包，选 Modify 或卸载后重装，并勾上这个选项。
提示 No such file or directory
“运行”那一步的 cd 没进入正确的文件夹。重新输入 cd 加空格，再拖一次文件夹。
弹窗要安装“命令行开发者工具”
说明官网的 Python 没装好，重新安装 .pkg 安装包。
一直显示“网络错误”
检查电脑能不能上网。网络恢复后程序会自动继续。
显示“HTTP 429 被限流”
请求太频繁了，程序会自动等 5 分钟再试，不用管。
改了 config.json 但没生效
需要先停止程序（CtrlControl + C），再重新运行。
完成的步骤会记在这台设备的浏览器里，下次打开还能看到。文字版教程也在程序文件夹的 README.md 里。
